## About Us

LoBot LLC is a fast-moving, AI-native startup dedicated to building better logistics solutions that help businesses future-proof their operations. We develop high-quality software products that empower organizations of all sizes to optimize their logistics, improve business efficiency and productivity, and accelerate growth through accessible technology.

## Our Mission

We are guided by three core principles:

### 1. Empowering Businesses Through Logistics & Productivity Solutions

We build robust solutions for small, medium-sized, and large-scale businesses to help them make better logistical and business decisions. Our tools are designed to boost employee productivity and streamline operational workflows across diverse industries and organizational scales.

### 2. AI-Powered Innovation with Open-Source Foundations

We accelerate our products with cutting-edge AI tools and established open-source frameworks, including but not limited to:
- **npm ecosystem** for package management and reusable components
- **Next.js** for server-side, production-grade web applications
- **JavaScript/TypeScript** as our primary languages
- **Bun** for fast runtime and tooling
- And other proven open-source technologies

### 3. Open Source Philosophy as Our Core

We believe in the power of open source to drive innovation, transparency, and community collaboration. Our products are built with open-source values at their foundation, and we actively contribute back to the ecosystems we rely on.

### 4. Scalable Solutions for Enterprise Environments

We help scale our products so teams can work effectively in any type of business environment—from startups to large enterprises. Our architecture is designed for growth, reliability, and maintainability at scale.

## What We Offer

- **Logistics optimization tools** for real-time tracking and decision-making
- **Business productivity solutions** that integrate with existing workflows
- **AI-enhanced features** that automate routine tasks and provide intelligent insights
- **Open-source-first approach** with transparent development and community engagement
- **Scalable architectures** that grow with your organization

## Technology Stack

Our products are built using modern web technologies and proven open-source frameworks.

The programming languages used across LoBot LLC's repositories (as of November 2026):

- <img src="https://cdn.simpleicons.org/typescript" alt="TypeScript" width="20" height="20" /> **TypeScript** — Primary language across all repositories (TecnoIndicator, homepage, .github)
- <img src="https://cdn.simpleicons.org/javascript" alt="JavaScript" width="20" height="20" /> **JavaScript** — Used in configuration files and build scripts
- <img src="https://cdn.simpleicons.org/css" alt="CSS" width="20" height="20" /> **CSS** — Styling via Tailwind CSS 4
- <img src="https://cdn.simpleicons.org/json" alt="JSON" width="20" height="20" /> **JSON** — Configuration and data files
- <img src="https://cdn.simpleicons.org/yaml" alt="YAML" width="20" height="20" /> **YAML** — CI/CD and configuration
- <img src="https://cdn.simpleicons.org/markdown" alt="Markdown" width="20" height="20" /> **Markdown** — Documentation

**Frameworks & Tools:**
- **Next.js 16** (App Router) — React framework for production-grade web applications
- **React 19** — UI library with concurrent features
- **Tailwind CSS 4** — Utility-first styling
- **Chart.js** — Interactive data visualization (TecnoIndicator)
- **Drizzle ORM** — Type-safe database ORM (homepage)
- **PostgreSQL** — Primary database (homepage)
- **Bun** — Fast runtime and tooling
- **pnpm** — Disk-efficient package manager
